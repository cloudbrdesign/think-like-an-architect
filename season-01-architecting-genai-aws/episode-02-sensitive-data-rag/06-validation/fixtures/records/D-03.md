# Project Orion delivery report

## §1 Background

Project Orion replaced the signalling controllers on the Kestrelmoor eastern line between two depots over eighteen months. Marker CANARY-INT-ORION-BACKGROUND.

## §2 Delivery

Delivery used staged commissioning at weekends, with depot access agreed four weeks ahead for each stage. Marker CANARY-INT-ORION-DELIVERY.

## §3 Lessons learned

Lessons learned on Project Orion: early depot access and staged commissioning reduced rework; late cable surveys caused two weekend overruns; a single change log for the whole project should be kept from day one. Marker CANARY-INT-ORION-LESSONS.
