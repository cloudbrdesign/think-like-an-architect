# Signalling maintenance procedure SMP-12

## §1 Fault isolation

Before work starts on a signalling controller at any Kestrelmoor depot, isolate the controller at the local distribution board, apply a personal lock and confirm isolation with the approved test lamp. Then test the relay interlocks one at a time and record each reading in the depot maintenance system. Marker CANARY-INT-SMP12.

## §2 Post-maintenance tests

After maintenance, restore power in the order given on the controller label, run the lamp-proving test and the route-setting test, and hand the controller back to signalling control only after both pass. Marker CANARY-INT-SMP12-TESTS.
